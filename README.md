Project Title

Derm AI – AI-Based Skin Disease Detection System

Brief Description

Derm AI is a machine learning-based web application designed to identify different types of skin diseases from uploaded skin images. The system helps users get quick preliminary analysis by predicting possible skin conditions using image classification techniques. It provides an easy-to-use interface where users can upload an image and receive prediction results instantly. The project aims to assist in early awareness and improve accessibility to basic dermatological analysis using artificial intelligence.
